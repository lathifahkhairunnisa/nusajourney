# NusaExplore V2 🇮🇩

## Explore the Stories of Indonesia

Versi kedua NusaExplore dibuat dengan tampilan yang lebih visual dan menggunakan **foto budaya nyata** melalui sumber Wikimedia Commons.

### ✨ Fitur
- Hero section dengan foto budaya Indonesia
- 7 wilayah eksplorasi
- Foto budaya nyata pada region cards dan culture cards
- Rumah adat, kuliner, seni, dan tradisi
- Interactive region switcher
- Dark mode
- Mini quiz
- Responsive design

### 📁 Struktur
```text
NusaExplore-V2/
├── index.html
├── style.css
├── script.js
├── README.md
└── assets/
    └── images/
        └── CREDITS.md
```

### 🖼️ Catatan gambar
Versi ini menggunakan URL gambar dari **Wikimedia Commons** agar gambar yang tampil merupakan foto budaya nyata, bukan emoji atau dummy image.

Jika ingin membuat versi 100% offline, gambar Wikimedia Commons dapat diunduh secara manual sesuai lisensinya dan disimpan ke folder `assets/images/`, kemudian URL pada `script.js` dan `style.css` dapat diganti menjadi path lokal.

### 🌐 Deploy ke GitHub Pages
Upload seluruh isi folder ke repository, lalu:
**Settings → Pages → Deploy from a branch → main → /(root)**
